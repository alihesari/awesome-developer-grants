# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The program must give developers or maintainers money, credits or paid time. A discount page with no published offer does not count.
- Link to the program's official page, not a blog post, a news article or a third-party review.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One-sentence description. Offer: concise published amount and who qualifies.`

- State only the amount and eligibility the official page publishes. If a number is not on that page, leave it out and say so.
- Do not add a program you cannot confirm is still running. A program with permanently closed applications belongs in Closed Programs.
- One program per pull request, unless the PR updates a whole section.

## Updating an entry

Grant terms, credit amounts and deadlines change all the time. If an amount changed, an eligibility rule moved or a program closed, open a pull request with the link to the official page that shows the change.
